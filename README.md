# 사형, 집행되지 않는 형벌

**부제 · 원문 아카이브 — 조문 · 판결 · 통계**

**지은이 · 응징과 정의 (Retribution and Justice)**

사형제를 부활시키자는 이야기가 아니다. 이미 확정된 형벌이 집행되지 않고 있다는 이야기다.

이 책은 **원문으로만** 쓴다. 법령 조문, 헌법재판소 결정, 대법원 판결, 법무부 통계 — 링크와 열람일을 남기고, 확인하지 못한 것은 확인하지 못했다고 적는다.

## 이 책이 답하는 질문

- 형법 제41조는 지금도 사형을 형의 종류로 두고 있는가
- 헌법재판소는 사형제를 어떻게 판단했고, 무엇은 판단하지 않았나
- 확정된 사형수 52명(군인 포함 56명)은 어떤 법적 지위에 있는가
- 형사소송법 제465조의 6개월은 무엇을 뜻하는가
- 집행도 폐지도 아닌 상태를 법으로 정한 적이 있는가

## 읽는 방법

1장부터 순서대로 읽어도 되고, 궁금한 장만 골라 읽어도 된다. 각 장은 그 자체로 완결된다.

## 표기 원칙

- **원문대조** — 법령·결정·판결·통계의 원문을 직접 확인한 것
- **부분확인** — 2차 자료를 통해 확인했으나 원문을 아직 보지 못한 것
- **미대조** — 인용하지 않는다

## 정정 원칙

이 책은 틀린 기록을 공개한다. **22장이 정정 이력**이다. 사실을 잘못 읽었으면 고치고 이력을 남기며, 규칙을 바꾸려면 사전등록 절차를 밟는다.
